# Dragon of Unindexed Data

Mini-app de gestión de metadatos de investigación. Pixel art original, caballero, castillo nocturno, dragón verde, efecto CRT y espectro de disciplinas.

## Uso

1. Añade un recurso o carga el ejemplo ficticio.
2. Completa título, autoría y repositorio.
3. Añade disciplina y etiquetas para formar la taxonomía.
4. Selecciona una relación explícita con otro recurso y anota su fundamento.
5. Consulta el mapa y busca recursos. El dragón se reduce y se convierte en un grafo conforme avanza la organización.

Guardado local en el navegador, exportación JSON/CSV e importación JSON con validación. Exporta una copia antes de cambiar de dispositivo o borrar datos del navegador. La importación sustituye el proyecto tras confirmación.

## Alcance y límites

No consulta automáticamente repositorios, no lee artículos completos, no comprueba citas ni deduce conexiones. Organiza los metadatos introducidos por la persona. El porcentaje mide tareas de organización, no calidad científica. Los ejemplos son ficticios.

Hasta 500 recursos por proyecto; el mapa dibuja los primeros 60. Cada recurso tiene una relación saliente editable. Sin sincronización, colaboración en tiempo real, IA ni servicios de pago. Los metadatos no se envían a servidores. Abrir una fuente sí navega al sitio elegido. GitHub recibe las peticiones normales de carga de la web.

## Desarrollo

HTML, CSS y JavaScript sin dependencias externas. Abrir con un servidor estático local o GitHub Pages.
